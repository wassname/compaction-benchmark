- Source-session `session_stats.cost` is copied historical cost, not a benchmark-call cost. Last-call usage is the relevant cost: an un-compacted lucid-aug20 DeepSeek answer used 118,867 input tokens and cost $0.115; a compacted answer used about 24k tokens and cost about $0.026.
- `pi-custom-compaction` resolves its summary model only with `modelRegistry.find`; Pi can start an FP8 custom ID but that extension falls back if the ID is absent from isolated `models-store.json`. Add the alias before it starts.
