## Hypotheses

### H1 [method | Likely | 65%]

- Mechanism: preserving opaque state did not improve these two fixtures relative to Pi's text summary.
- Evidence: `OPENAI_NATIVE_RESULTS.md` reports `13.2±2.0` native retained facts and `14.5±1.5` text retained facts across 6/6 cells.
- Contrary evidence: native has a slightly higher pre mean, `6.0±3.2` versus `5.7±2.6`.
- Discriminating test: add fixtures with the same validated replay evidence. A stable positive paired retained difference would contradict this reading.
- Fix/action: do not rank native V2 above text summary from this table.
- Interpretability: partial; it applies only to the tested fixtures, local patch, and Terra endpoint.

### H2 [data | Likely | 60%]

- Mechanism: fixture and generation variance dominate a six-cell comparison.
- Evidence: paired pre differences are `[+1, 0, +1, -2, 0, +2]`; retained differences are `[-1, -4, +1, -3, -2, +1]`.
- Contrary evidence: five of six retained differences favour Pi text summary.
- Discriminating test: run more fixture families without changing model, patch, or judge protocol.
- Fix/action: report the means and per-fixture cells, not a broad winner claim.
- Interpretability: yes for observed sample means; no for general ranking.

### H3 [bug | Chances a little better than even | 50%]

- Mechanism: the local serializer/replay patch may change the effective history in a way not equivalent to stock native V2.
- Evidence: stock V2 first returned `Store must be set to false`; the local checkout also contains replay alignment changes for Pi's encrypted-thinking representation.
- Contrary evidence: every native cell records a V2 strategy and a native-rewrite event, so this is not the prior text-summary fallback.
- Discriminating test: upstream or independently reproduce the `store: false` and replay mapping changes, then repeat the same cells.
- Fix/action: label this row as a local endpoint/replay patch, not stock `pi-better-compaction`.
- Interpretability: partial.

### H4 [measurement | Likely | 65%]

- Mechanism: skipping individual invented-claim checks removes one response-quality screen.
- Evidence: every final grade has `"invention_check": "skipped"`; job 266 failed because only two seats completed the full pass.
- Contrary evidence: the fact-label rubric is the table metric, and all selected judges had earlier passed calibration including the invention check.
- Discriminating test: use a bounded invention prompt or shorter source material and compare fact labels with and without that pass.
- Fix/action: retain the fact-only limitation in the table and do not treat the result as an invention-safety measure.
- Interpretability: yes for panel fact recall; no for unsupported extra claims.

## Decision

- Resolve condition: met for the bounded fact-recall table. Job 264's stated condition was six V2 checkpoints plus six native replays; both were observed. Job 270's stated condition was matched 6/6 fact-only rows; all twelve grade files exist.
- Earliest unsupported link: “opaque encrypted state improves recall.” The replay artifacts establish delivery, not benefit.
- Validity: `P(result is invalid) ≈ 0.25–0.40` for the narrow fact-recall comparison, mainly due to the local patch and skipped invention check. It is an inconclusive comparison, not a credible positive for native V2.
- Highest-information clues: (1) six native-rewrite records show the native state was used; (2) paired retained differences favour text in five cells; (3) job 266 isolates the grading limitation from the compaction path.
- Missing measurements: more fixtures; an upstream implementation of the two local changes; bounded invention screening.
- Recommended sequence: preserve this separate, labelled table. Do not merge it into the DeepSeek ranking. Before a larger native benchmark, make the local patch reproducible and add a bounded answer-quality screen.
